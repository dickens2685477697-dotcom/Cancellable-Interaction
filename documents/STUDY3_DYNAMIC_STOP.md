# Study3 Dynamic Stop

在 Study3 场景中选择 `Spawner`，将 `Mode Selected` 设为 **16. Dynamic Stop**（枚举值 30）。
本次新增模式，不自动更改场景当前保存的选择技术。

参数位于 Spawner Inspector 的 `Shared Selection Technique Settings` →
`Dynamic Stop (demo motion logic)`，也可以直接编辑
`Assets/Scripts/Study3/Study3SelectionSettings.asset`。
未指定共享配置时，Spawner Inspector 直接显示对应参数。

| Inspector 参数 | 初值 | 含义 |
| --- | --- | --- |
| Sample Interval (ms) | 16 | 最短测量间隔，使用实际经过时间计算运动；不是长按等待 |
| Speed Minimum (m/s) | 0.02 | 速度阈值的非零下限 |
| Speed Maximum (m/s) | 0.12 | 速度阈值上限 |
| Speed Gain | 0.10 | 近期速度对速度阈值的增量比例 |
| Acceleration Minimum (m/s²) | 0.5 | 加速度阈值的非零下限 |
| Acceleration Maximum (m/s²) | 4 | 加速度阈值上限 |
| Acceleration Gain (1/s) | 3 | 近期速度对加速度阈值的增量系数 |
| Speed History Decay (s) | 0.18 | 高速历史指数衰减的时间尺度；不是停留确认时间 |

速度与加速度使用世界空间的米制单位。默认阈值是 VR/AR 试调起点，
不能视为原 HTML 的 CSS 像素阈值已经完成真实设备换算或校准。

## 测量与触发

每个渲染帧读取被追踪的食指尖，累计相邻观测位置间的距离。达到测量间隔后：

```text
速度 = 累计路程 / 实际时间
速度向量 = 本段终点位移 / 实际时间
加速度 = max(速度向量变化的长度 / 实际时间, 路程速度变化的绝对值 / 实际时间)
近期速度 = max(本段速度, 上次近期速度 × exp(-实际时间 / 衰减时间))
速度阈值 = min(速度上限, 速度下限 + 近期速度 × 速度增益)
加速度阈值 = min(加速度上限, 加速度下限 + 近期速度 × 加速度增益)
```

指尖在球内、加速度历史已准备好，且速度和加速度同时不超过对应阈值时触发。
第一段测量只收集速度，下一段才有加速度；不把缺少历史数据当作零加速度。
测量持续在球外进行，因此高速进入目标前的近期运动也会参与动态阈值。
使用球形 Collider 的真实球面边界，不使用球的包围盒角落作为触发区。

触发之后，在球内再次移动仍保持已触发状态，同一次接触只产生一个选择或误触事件。
移出球外清除激活状态；追踪丢失、禁用对象或对象池重新配置时清除运动历史。
球内停止时仍继续测量，不设最小位移过滤，也不要求长按、压力、角度或后续位移。
输入采样只能保留设备已提供的观测轨迹，无法恢复渲染帧之间未被观测的运动。

目标球沿用进入反馈、准备圆环、正确/雷球声音和实验完成流程。
障碍物使用同一测量算法，达到条件时记录误触；移出后恢复进入前的材质。
现有实验流程在目标选择成功后推进到下一个目标；Intro 独立预览可以保留成功反馈。
雷球未触发前移出，沿用实验中的成功取消流程。

轨迹 CSV 的 `V_vec`、`A_vec`、`isVOK`、`isAOK` 在新模式下使用新检测器数据。
未触发原因会记录当时的速度、加速度及对应动态阈值。触发条件代码为 `M`。

## 验证

Unity 菜单 **Study3 → Validate Dynamic Stop** 可运行算法、球面边界和共享参数回归检查。
实现时已使用 Unity 自带 C# 编译器通过 Runtime/Editor 编译，并通过 10 项纯运动算法
回归检查及 8 个 Inspector 参数的序列化、标签、Tooltip 和共享设置路由检查。
本机 Unity 许可证过期，编辑器原生球面/SerializedObject 检查和设备交互验证尚未运行。
真实设备上还应确认：快速穿过不误触、停止后触发、急减速当段不提前触发、
小幅抖动可触发、触发后继续移动不重复记录，以及移出/丢失追踪/重入复位。
